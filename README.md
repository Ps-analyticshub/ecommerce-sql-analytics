# 🛒 E-commerce Customer & Sales Analytics using MySQL

## 📊 Project Overview

This project presents an **E-commerce Customer & Sales Analytics Solution** built using **MySQL** to analyze customer purchasing behavior, product performance, revenue trends, and inventory metrics.

The analysis helps businesses understand **customer value, sales performance, product demand, and operational insights** to support data-driven decision-making.

The project focuses on uncovering trends related to **customer transactions, revenue generation, product sales, and inventory management**.

---

## 🎯 Objectives

* Identify **top revenue-generating customers**
* Analyze **monthly sales and revenue trends**
* Determine **best-selling and highest revenue products**
* Evaluate **customer purchasing frequency and spending behavior**
* Detect **low-stock inventory products**
* Identify **inactive customers for retention strategies**
* Generate **business insights using SQL analytics**

---

## 🛠 Tools & Technologies Used

* **MySQL** – Database creation and analysis
* **MySQL Workbench** – Query execution and database management
* **SQL** – Data querying and business analysis

---

## 📈 Analysis Insights

The project provides insights such as:

* Identification of **top 10 customers by revenue**
* Analysis of **monthly revenue trends**
* Detection of **best-selling products**
* Revenue contribution by **product and city**
* Identification of **highest spending customers**
* Monitoring of **low-stock inventory**
* Detection of **inactive customers**
* Product pricing and revenue distribution analysis

These insights help businesses improve **sales strategy, customer retention, and inventory planning**.
